SERVICES PANEL PHOTOS
=====================
Drop six photographs here, named exactly:

  01-strategy.jpg    Creative Strategy    research / strategy board / compass /
                     target / dark desktop planning
  02-identity.jpg    Branding & Design    brand identity, typography + colour
                     swatches, design studio desk
  03-content.jpg     Social Media         content creation, filming on a phone,
                     ring light, feed layout
  04-production.jpg  Film & Photography   on-set lighting rig, cinema camera,
                     production moment
  05-digital.jpg     Web Experiences      code / UI screen, motion + UI design
                     workspace
  06-experience.jpg  Events & Organization  live stage lighting, activation, crowd

Format
  - Landscape, 1600x1200 or larger (each panel is roughly half a viewport wide,
    full height, cropped with object-fit: cover).
  - JPG, ideally under ~300 KB each. Keep the .jpg extension or update the
    img: paths in SEPA_CONTENT (both the en and tr service lists).
  - Low-key / dark frames sit best: the CSS applies
    grayscale(1) contrast(1.15) brightness(.55) and screens an orange
    (--accent) beam over the bottom-right corner, so the photo reads as a
    duotone rather than as stock photography.

Until a file exists the panel silently falls back to the original line-art
mark, so the site never shows a broken image.
